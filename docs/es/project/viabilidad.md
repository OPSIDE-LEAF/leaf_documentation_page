# Viabilidad y modelo de negocio

## Oportunidad

- **Nicho desatendido**: las agencias de la ZMG (datos Clutch.co / GoodFirms) cobran 25–99 USD/hora con arranques de 5,000–25,000 USD, excluyendo sistemáticamente al segmento PyME.
- **Control de costos técnicos**: todo el stack (Kotlin, Compose, Gradle, kotlinx.*) es open source o gratuito.
- **Modelo con potencial de expansión**: open core con setup fee y licenciamiento de módulos avanzados.

## Análisis FODA

| Fortalezas | Oportunidades |
|---|---|
| Conocimiento técnico en Kotlin, Android e iOS | Mercado PyME de GDL desatendido y en crecimiento |
| Stack maduro validado en producción global | Comunidad open source receptiva a recursos educativos KMP |
| Diferenciación clara vs híbridos (rendimiento nativo) | Tendencia global de adopción de KMP en producción |

| Debilidades | Amenazas |
|---|---|
| Equipo reducido (2 integrantes) con calendario académico | Dependencia del ecosistema KMP y decisiones de JetBrains |
| Curva de aprendizaje inicial elevada | Competencia indirecta de No-Code / Low-Code |
| Dependencia de la madurez de Compose MP en iOS | Cambios disruptivos en APIs de Android/iOS |

## Modelo de ingresos (open core)

| Vía | Modelo |
|---|---|
| Open Core + módulos | Core gratuito; módulos básicos gratis, avanzados por licencia |
| Suscripción a módulos avanzados | ~5 USD/mes por módulo |
| Setup fee | Cuota inicial por proyecto (variable según alcance) |
| Marketplace de módulos | Comisión 10–20% por módulos de terceros |
| Módulos por industria | Salud, fintech, retail — nichos recurrentes |
| Servicios empresariales | Soporte, implementación, personalización |
| Capacitación y consultoría | Formación de equipos; migración y optimización |

Cada módulo es un activo de propiedad intelectual licenciable, enseñable e implementable repetidamente, sin costo de reproducción.

## Números del plan

**Inversión inicial: $13,700 USD** — equipo de cómputo ($2,200) + 460 horas de desarrollo (230 por integrante × $25 USD/h, banda inferior del mercado local); herramientas $0 (open source).

| Actividad | Horas |
|---|---|
| Diseño de arquitectura | 60 |
| Núcleo del framework | 120 |
| Módulos funcionales | 100 |
| Integración con app demostrativa | 80 |
| Pruebas y depuración | 60 |
| Documentación técnica | 40 |

**Operación anual: $6,572 USD** — mantenimiento y actualizaciones ($6,000), servidor Maven ($300), publicidad inicial ($200), hosting de docs ($60), dominio ($12).

## Conclusión

El proyecto es viable técnica, económica y operativamente: inversión inicial absorbible durante el ciclo académico, costos operativos sostenibles con el modelo open core, riesgos mitigados por diseño (arquitectura agnóstica a la herramienta) y un mercado identificado y documentadamente desatendido para validar la propuesta.
