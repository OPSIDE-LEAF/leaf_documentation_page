# Glosario

| Término | Significado |
| --- | --- |
| Action | una operación que recibe datos y devuelve una respuesta |
| Workflow | una sesión para UI con estado, eventos y una o varias pantallas |
| `WorkflowStep` | la decisión siguiente: continuar, pedir trabajo o terminar |
| Effect | trabajo que puede tardar, como guardar o consultar algo |
| Outcome | la respuesta final: terminó, falló o se canceló |
| Port | una interfaz que permite a la app entregar red, almacenamiento u otro servicio |
| Holder | el objeto Compose que observa una sesión Workflow |
| Maven Local | una carpeta local desde la que se prueban artefactos |

Estos términos describen la API y el runtime. La distribución de artefactos y la configuración de servicios externos son decisiones separadas de cada aplicación.
