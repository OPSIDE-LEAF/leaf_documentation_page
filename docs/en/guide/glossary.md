# Glossary

| Term | Meaning |
| --- | --- |
| Action | one operation that receives data and returns an answer |
| Workflow | one UI session with state, events, and one or more screens |
| `WorkflowStep` | the next choice: continue, request work, or finish |
| Effect | work that can take time, such as saving or looking something up |
| Outcome | the final answer: completed, failed, or cancelled |
| Port | an interface through which the app provides network, storage, or another service |
| Holder | the Compose object that watches a Workflow session |
| Maven Local | a local folder from which artifacts are tested |

These terms describe the API and runtime. Artifact distribution and third-party service configuration are separate application decisions.
